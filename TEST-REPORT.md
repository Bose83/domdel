# Проверки сборки для Netlify

Дата: 18 октября 2026. Проверки выполнялись локально на Node.js 24.19; проект рассчитан на Node.js 22.13+. Это отчёт о конкретных автоматических проверках, а не утверждение о безошибочности всех возможных сценариев.

| Область | Проверено |
| --- | --- |
| Аккаунты | Регистрация без email, вход, хранение хешей вместо паролей и восстановительных кодов |
| Устройства | Защищённый cookie на 180 дней, повторное открытие клиента без формы входа, выход со всех устройств |
| Восстановление | Новый пароль, смена восстановительного кода, отказ для старого кода, отзыв старых сессий |
| Семьи | Создание разных комнат, отсутствие чужих данных в ответе, вступление с подтверждением, экспорт своей комнаты |
| Права | Запрет подмены профиля, организаторских действий обычному участнику, исключения создателя, доступа исключённого участника |
| Совместные действия | Повтор одного запроса не начисляет награду снова; устаревшее действие отклоняется; чужое дело нельзя завершить |
| Дела | Создание, взятие, принятие назначения, передача конкретному человеку, завершение |
| Таймеры | Запуск, пауза, истечение, продление, завершение подхода, отсутствие двойной награды в тот же день |
| Шаблоны | Добавление 19 заготовок без дубликатов, создание своего повторяющегося шаблона, необходимость согласия назначенного человека |
| Награды | Самооценка, внешний отзыв, штраф и его возврат, согласование цели ребёнка, выдача награды |
| Содержимое | Помещения, память комнаты, календарное событие, сообщения, экранирование HTML |
| Импорт | Текстовый список с просмотром и подтверждением, отказ для неизвестного исполняемого поля |
| Push | Тихие часы, режим без уведомлений, упоминания, защита адреса подписки от SSRF, дедупликация, отзыв подписки при выходе |
| Клиент → API → база | Автоматическое прохождение регистрации, сохранения восстановительного кода, создания комнаты/дела и повторного открытия в DOM-окружении |

Команды: `npm test`, `npm run check:functions`, `npm audit --omit=dev`.

Тесты API и push используют реальный движок PostgreSQL в PGlite с обеими SQL-миграциями. PGlite работает через одно соединение, поэтому проверка устаревших запросов и повторов не заменяет нагрузочный тест нескольких настоящих PostgreSQL-соединений. В production используются транзакции и блокировки строк PostgreSQL.

Что не проверено здесь:

- Публикация в аккаунте пользователя, фактическое создание Netlify Database и рабочие URL.
- Визуальное отображение на физических iPhone/Android. Браузер для такой проверки в среде недоступен; DOM-тест не выдаётся за реальную проверку Safari или Chrome.
- Доставка push через Apple/Google/Mozilla на настоящие устройства. В тестах отправитель заменён контролируемой функцией; реальная подписка требует HTTPS, разрешения и VAPID-ключей.
- Массовая нагрузка, внешнее проникновение и все сочетания действий/ролей. Перед публичным сервисом для большого числа семей нужны отдельные испытания.

После публикации: зарегистрируйте два аккаунта на разных телефонах, подтвердите вступление, возьмите общее дело на одном и проверьте результат на другом. Закройте и снова откройте приложение. Если нужны push, включите их добровольно на каждом телефоне и проверьте одно ближайшее событие, затем тихие часы.
